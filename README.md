# 🏢 Simple Project PHP Modular Monolith Architecture

This project is a scalable, modular monolith system designed using **MVC**

## 📦 Current Modules

- Features:
  - Role creation and management
  - Assign permissions to roles
  - Assign roles to users
  - Middleware for route protection

- Getting Started:
  - composer install
  - cp .env.example .env
  - php -S localhost:8000 -t public
